Set the Background: Open Synfig Studio, navigate to Layer > New Layer > Geometry > Solid Color, and establish an orange background.

Draw the Flagpole: Use the Rectangle Tool to draw a tall vertical rectangle, change its color to brown, and cap the top with a smaller black rectangle.

Apply 3D Bevel: Right-click the pole layer, select New Layer > Stylize > Bevel, and adjust the depth and light angle to make the pole look cylindrical.

Design the Fabric: Draw a large black rectangle extending from the pole, then use the Circle Tool to place a maroon circle in the center.

Insert Custom Text: Navigate to Layer > New Layer > Other > Text, type the required text, and center it over the maroon circle.

Group the Elements: Select the black fabric, circle, and text layers, group them into a single folder, and name it to keep the layers organized.

Shape the Fabric: Right-click the grouped folder, choose New Layer > Distortions > Curve Warp, and adjust the control points to give the flag a curved shape.

Animate the Ripple: Add a New Layer > Distortions > Noise Distort to the group, tweaking the Displacement and Animation Speed parameters to create continuous movement.

Mask and Render: Refine the outer edges of the flag using the Spline Tool as a mask, then open the Preview Window to render the final animation.
